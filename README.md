# The Artist’s House

Build a beautiful, immersive 3D portfolio website for my artist friend, designed like a real architect-designed home turned into a personal art gallery.

Instead of a traditional portfolio with cards, let visitors explore a realistic 3D house with beautiful interiors, natural lighting, wooden floors, and walls decorated with picture frames displaying her paintings and drawings.

Key features:

Create a realistic, interactive 3D home with multiple rooms, stairs, corridors, and gallery spaces.

Add empty picture frames where she can easily upload her digital paintings and add titles, descriptions, and stories about each artwork.

When someone clicks a painting, open a beautiful full-screen preview with its details and smooth animations.

Add immersive camera movement, scroll-based transitions, and up/down, left/right navigation to explore the house naturally.

Include a small, live, interactive floor map in the bottom-right corner showing the current location and allowing visitors to jump directly to any room.

Add an artist introduction, personal story, Instagram link, and contact section.

Make the design elegant, artistic, realistic, and cinematic, with smooth animations and subtle interactions.

Ensure everything works beautifully on desktop, tablets, and mobile devices, with touch controls and performance optimization.

Use React, TypeScript, Three.js, React Three Fiber, and Drei if appropriate. Keep the architecture, artwork data, and navigation modular so new paintings and rooms can be added easily.

First inspect the existing project, then build the actual working website—not just a mockup. Focus on realistic architecture, intuitive navigation, beautiful artwork presentation, and a seamless user experience. Make the result feel like walking through an artist's home and discovering her creativity in every room.
